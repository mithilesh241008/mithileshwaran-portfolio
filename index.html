04 — Selected work

Things I've built

Four projects on GitHub: one live store, one demo, and two AI experiments I'm still working on.

  1. 01

    Akram Perfumes

    An online store I built for Akram Perfumes, a fragrance brand from Madurai. It has product variants and sizes, customer accounts, a cart with Razorpay checkout, and an admin dashboard for products, stock and orders.

    Live

    Next.js · TypeScript · Tailwind CSS · Supabase · Razorpay

    Repo ↗ Live site ↗

  2. 02

    SRM IST Canteen

    Lunch queues at our canteen get long, so I built a way to order before you get there. Students pick food, get a daily token and collect when it's ready. The kitchen moves orders through an admin dashboard. A student demo, not an official SRM app. Payments are simulated.

    Demo

    Next.js · TypeScript · Tailwind CSS · Supabase

    Repo ↗ Demo ↗

  3. 03

    CareLink AI

    A Streamlit app for everyday health questions, made with rural users in mind. You can ask in English or Tamil and have the answer read aloud. It also has a BMI calculator and a simple fitness planner. General guidance only, not medical advice.

    Prototype

    Python · Streamlit · Gemini API · gTTS

    Repo ↗ Live app ↗

  4. 04

    Arcus

    A personal assistant that runs on my own laptop. It talks to a local phi3 model through Ollama and speaks its replies with the Windows voice. For now it takes typed input. Voice input isn't wired up yet.

    In progress

    Python · Ollama · phi3
